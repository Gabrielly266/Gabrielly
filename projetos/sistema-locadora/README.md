# Sistema de Locadora

Projeto acadêmico desenvolvido durante a graduação em Sistemas de Informação no IFES Campus Colatina.

## Objetivo

Organizar o cadastro de filmes, clientes e locações em uma aplicação integrada a um banco de dados relacional.

## Escopo trabalhado

- Modelagem das entidades de gênero, filme, fita, cliente, locação e itens da locação.
- Cadastro, consulta, atualização e exclusão de registros.
- Controle de disponibilidade das fitas para locação.
- Consultas SQL e integração entre a aplicação e o PostgreSQL.

## Tecnologias

Python, PostgreSQL, SQL e modelagem de dados.
