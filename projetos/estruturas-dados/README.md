# Estruturas de Dados em C e C++

Conjunto de atividades acadêmicas sobre organização, busca e manipulação de dados.

## Conteúdos trabalhados

- Leitura de registros de alunos armazenados em arquivos CSV.
- Implementação de listas duplamente encadeadas.
- Utilização de um vetor com 100 posições para distribuição de registros.
- Definição do índice a partir dos dois dígitos verificadores do CPF.
- Inserção de alunos em ordem alfabética.
- Busca de registros por CPF e, em versões anteriores, matrícula.
- Verificação de CPFs duplicados.
- Remoção de registros.
- Medição do tempo de execução das operações.

## Tecnologias

C, C++, estruturas de dados, arquivos CSV e análise de desempenho.
